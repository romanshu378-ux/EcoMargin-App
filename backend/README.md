# EcoMargin Backend - Service Configuration

This subdirectory contains the Spring Boot application source code, Dockerfile, database migration scripts, and dependency definitions for EcoMargin.

## Quick Start (Build)

```bash
mvn clean package -DskipTests
```

## Docker Build

```bash
docker build -t ecomargin-backend .
```

Refer to the root [README.md](../README.md) for full Render deployment documentation.
